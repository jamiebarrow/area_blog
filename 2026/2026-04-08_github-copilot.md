# 2026-04-08 - Github Copilot

I have been playing around a bit with Github Copilot lately.
I've tried it with Rider, Visual Studio and Visual Studio Code, and I have to say that I'm finding VS Code the best experience so far.

I do like how Rider provides a way to onboard a solution with Github Copilot, or I guess any AI agent via generating an `AGENTS.md`,
though I find the general experience of VS Code is just smoother. Typing `/init` to initialize it with the various customizations is nice.

I also was digging into some of the VS Code prompts, and looking at the Markdown for these, and the one even helped me learn a bit about
the use cases that each of the different files are used for.

Coincidentally, I stumbled upon a nice YouTube video from James Montemagno going into the UI of this, which I just discovered and figured it was there for a while,
but apparently it is recent (video itself is from a day ago too).

I haven't watched it yet, but I also plan to check out the linked video by Kayla Cinnamon which explains them as well.

I am quite excited by what is possible with all the various AI and Agentic programming tools.

I feel inspired to go start making my own custom instructions, hooks, etc. and MCP servers for my own needs.
